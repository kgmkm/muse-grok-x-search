# muse-grok-x-search

> English version: [README.md](README.md)

Muse に **X（旧Twitter）検索** を追加する専用スキルです。

Muse の標準機能では、ソーシャル検索の対象は Instagram / Facebook / Threads で、X は検索できません。このスキルは、xAI のコーディングエージェント **Grok Build** の CLI を Muse から呼び出し、その内蔵ツール `x_search` で公開ポストを検索できるようにします。

## 特徴

- **X の生の反応が取れる** — 話題のポスト、リプライ、引用を、日付・アカウント・URL付きで取得
- **読み取り専用に設計** — 検索用プロンプトに書き込み操作（投稿・返信・いいね・リポスト・フォロー）の禁止を明記し、調査だけに使います
- **追加の API 契約は不要** — Grok Build のサブスクリプション（SuperGrok / X Premium 系プラン）の範囲で動作します ※対象プランは変わることがあるため、導入時に公式情報を確認してください
- **実測済み** — 筆者環境（Muse の VM、2026-11-01）で、X Premium アカウントのデバイスコード認証から検索まで動作確認済み。1回の検索は約26秒でした

## 必要なもの

- Muse（シェルが使える環境）
- [Grok Build](https://x.ai) の CLI（公式インストールスクリプトで導入）
- Grok Build が使えるアカウント（SuperGrok / X Premium 系プラン、または `XAI_API_KEY`）

## インストール方法

Muse に、このリポジトリの URL を伝えて「スキルを入れて」と頼むだけで導入できます。

手動で入れる場合は、`SKILL.md` と `skill.yaml` を Muse のカスタムスキル置き場（`~/workspace/custom-skills/grok_x_search/`）に配置してください。

初回だけ、Grok Build へのサインインが必要です。Muse がデバイスコード方式のサインインを開始するので、表示された URL を自分の端末で開き、自分の X アカウントで承認してください。認証情報は自分の環境内にだけ保存されます。

## 使い方

導入後は、Muse に普通に頼むだけです。

- 「X で ○○ への反応を調べて」
- 「先週公開した自分の投稿の引用やリプライを集めて」
- 「○○ の発表について、X ではどう受け止められている？」

### ユースケース

- 自分の投稿・プロダクト・記事への反響チェック
- リリース直後の界隈の反応や不具合報告の収集
- ニュースや発表に対する一次反応の確認
- 特定アカウント群の発信の追跡

## 注意点

- 検索は Grok Build のサブスクリプション枠を消費します。範囲を絞った検索を低頻度で使うのがおすすめです
- Grok Build はベータ版のため、仕様や対象プランが変わる可能性があります（本書は 2026-11-01 時点の検証に基づきます）
- 検索結果は Grok が要約した内容です。重要な判断には、必ず元のポストを URL から確認してください

## 利用ルール

- 自分のアカウントと自分のサブスクリプションで使ってください。認証情報を他人と共有しないでください
- このスキルは調査専用です。投稿・返信・いいね・フォローなどの書き込み用途には使わないでください
- 他人のポストを引用するときは最小限にし、出典（アカウントと URL）を明示してください

## 規約調査と公開判断

このスキルを公開するにあたり、X / xAI の規約と、類似ツール（SearXNG の旧 Twitter エンジン等）が消えた経緯を調査しました。その結果に基づき、2026-11-02 時点で公開する判断をしています。調査内容と判断の根拠は [docs/terms-research.md](docs/terms-research.md) にまとめています。

## ついで検証：SearXNG / RustXNG

「セルフホスト型のメタ検索で Muse の検索を強化できないか」も同じ環境で検証しました。結論だけ書くと、週末イベントのような日本語ローカル検索では Muse 標準検索が最も実用的で、X 検索エンジンは SearXNG / RustXNG のどちらにも存在しませんでした。詳しくは [docs/findings.md](docs/findings.md) を参照してください。
