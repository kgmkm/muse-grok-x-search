# 検証メモ：SearXNG / RustXNG を Muse の VM で試した結果

検証日：2026-11-01
検証環境：Muse の VM（Linux x86_64、メモリ約8GB）
目的：セルフホスト型メタ検索で Muse の検索を強化できるか、および X 検索の代替経路になるかを確認する

## 結論の要約

- 日本語ローカル検索（地域イベント情報）では、Muse の標準検索が最も実用的だった
- Python 版 SearXNG は VM 内で動作し、エンジンを選べば（一例：google cse 単独）標準検索に迫る結果が返る
- RustXNG は設定 `[outgoing] verify = false`（証明書検証オフ）で VM 内でも動作した（v0.26.0 で実測）。ただし既定のエンジン構成ではタイムアウトが多く、実用にはエンジン選別が必要
- **X（Twitter）検索エンジンは、SearXNG / RustXNG のどちらにも存在しない**。X の反響調査には Grok 経由の x_search が必要

## RustXNG（sahenjp/RustXNG v0.24.0）

良い点（実測）:

- 単一バイナリ配布で導入が簡単。起動は一瞬で、常駐メモリは約14MB（公称13MiB）
- SearXNG のエンジン定義を広く移植し、エージェント向けの追加パラメータ（件数制限、ドメイン絞り込み、本文一括取得など）がある

証明書検証まわり:

- この VM の外向き通信はプロキシ経由で、証明書の検証に環境固有の CA が関係する
- RustXNG の HTTP 実装（reqwest + rustls）は同梱のルート証明書のみを信頼し、環境の CA を「追加する」設定はないため、既定の `verify = true` では全エンジンが証明書検証エラーになった（2026-11-02 追記：初回検証ではこの切り替え設定を見落としていた）
- 一方、SearXNG 互換の `outgoing.verify` 設定があり、`verify = false` で証明書検証自体をオフにすると、この VM でも検索が返ることを v0.26.0 で実測した（地域イベント検索で 12 件・約 3 秒、常駐メモリ約 23MB）
- ただし既定のエンジン構成のままでは、この出口 IP からはタイムアウトするエンジンが多く（44 件が無応答になる例も）、実用にはエンジン選別とタイムアウト調整が必要。duckduckgo と bing は動作を確認した
- 検証オフは万能の解法ではなく、あくまで「動かすための回避策」。正式に独自 CA を信頼させるには、ソース側でルート証明書を追加する改変が必要（`src/network.rs` のクライアント構築部）

## Python 版 SearXNG（公式リポジトリから導入）

- 依存関係を含めて導入でき、VM 内で正常に起動した（常駐メモリ約70〜100MB）
- 注意：PyPI の `searxng` パッケージはサーバー本体ではなく MCP ラッパー。本体は公式リポジトリから導入する
- エンジンの相性は出口 IP に大きく左右された（データセンター系 IP の実測）

| エンジン | 日本語ローカル検索 | 備考 |
| :--- | :--- | :--- |
| google cse | ◎ 0.4秒・20件、公式サイトや地域ブログが上位 | 複数エンジン同時実行時はタイムアウトすることも |
| bing | × 日本語クエリでも英独の無関係な結果 | IP の地域判定が優先される様子 |
| duckduckgo / brave | × タイムアウト後に自動停止 | ボット対策とみられる |
| google | × access denied |  |
| yandex / startpage | △ 英語クエリでは動作 | 日本語ローカルには弱い |
| wikipedia | ○ 結果は infobox として返る |  |

- 既定の general 検索は、上記の相性のせいでそのままでは実用にならなかった。エンジンを絞って使う前提の道具

## X 検索エンジンの有無（全走査）

- RustXNG の `settings.toml`（285件のエンジン定義）と、Python 版 SearXNG の `searx/engines/` および `settings.yml` を、twitter / nitter / x.com で全走査し、いずれも該当なし
- social media カテゴリには mastodon、lemmy、peertube などが含まれるが、X は含まれない
- Python 版の settings.yml で twitter が現れるのは、結果リンクの twitter.com を Nitter インスタンスへ書き換えるホスト名プラグインのコメント例のみ
- 前身の searx には twitter エンジンが存在した時期があるが、現行の SearXNG には残っていない

## Muse 標準検索との使い分け（筆者結論）

- 通常の Web 調査と日本語ローカル情報：Muse 標準検索
- X 上の反響・一次情報：Grok Build 経由の x_search（本リポジトリのスキル）
- 大量の定型クエリや特定エンジンへの一括問い合わせが必要になったら、セルフホスト SearXNG を再検討
